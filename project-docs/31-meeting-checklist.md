KUL WEBSITE: FIRST MEETING (1 HOUR)

BEFORE THE MEETING

- Push latest code, make sure the live site looks right
- Test run: intro film, search, quote form, Journey page
- Log into Vercel, open the Domains page
- Print the photo shot list for Mark
- Charge phone, open the site on it
- Start Zoom recording as soon as the call starts, tell Mark

THE HOUR

- 0:00 Hello + plan for the hour (3 min)
- 0:03 Walk through every page, write down all feedback (32 min)
  - Home, search, Services, Safety, Carrier Packet, Quote, Contact, Drivers, About,
    Journey, Road Ahead, 404, phone check
- 0:35 Connect the domain (15 min)
  - Add kulenterprises.com in Vercel, copy the records it shows
  - Mark logs into Squarespace, update the DNS records
  - NEVER touch the email (MX) records
  - Mark creates a Resend account, add its records too
  - Put the Resend API key into Vercel
  - Send a test quote, watch it land in his inbox
- 0:50 What I need from Mark (8 min)
  - Truck and freight photos (hand him the shot list)
  - This week: GA4, Search Console, Business Profile postcard
  - Business details: MC number, W-9, insurance certificate, authority letter,
    packet turnaround, trailer measurements
- 0:58 Wrap (2 min)
  - Book the editing training session
  - Read the feedback list back to him
  - Launch happens when photos + documents are in

AFTER THE MEETING

- Update the site URL setting, push, run the share-image check
- Check /admin still logs in on the new domain
- Send Mark the feedback list and his to-do recap
- Later, from his homework: GA4 Measurement ID + Search Console verification
  (both go into Vercel)
