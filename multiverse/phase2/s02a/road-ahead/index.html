(01) — The Written Number An honest count, both ends of it

One tractor today. Fifty by the end of 2029.

OneTractor today — 2026 → FiftyBy the end of 2029

Trust starts with an honest number, so here are both of ours. Everything between them will be earned the same way the first truck was — one dependable lane and one well-kept promise at a time.

(02) — How We Get There The lane stripe draws as you travel

(The Route) — Growing with Intention

(M—01) Prove the standard

One truck, run flawlessly: inspected before every pull, hours logged legal, the phone answered. The first tractor is the audition for every tractor after it.

(M—02) Earn repeat lanes

Growth is funded by kept promises — shippers who call back because the last load arrived the way we said it would. No lane is added faster than it can be run right.

(M—03) Add trucks deliberately

A tractor joins the fleet when the work behind it is already dependable — never to look bigger, only to serve better. Each addition carries the same standard as the first.

(M—04) Grow the people first

Drivers join the way customers do: on trust. Every seat we add belongs to someone who treats your freight the way the founder treated his first load.

(M—05) Arrive at fifty, unchanged

By the end of 2029, the plan reads fifty tractors — with the same pre-trip, the same straight answers, and the same person-first standard we run today.

No milestone above invents a date or a count — only the two written numbersOne → Fifty

(03) — The Growth Ledger Two columns, kept in balance

(The Ledger) — What Grows, What Doesn’t

What grows

  • (A)The fleet — from one tractor toward fifty by the end of 2029.
  • (B)The lanes — more of the country served directly, without a broker maze.
  • (C)The team — drivers and dispatch added seat by seat, on trust.
  • (D)The relationships — every kept promise compounds into the next call.

What never changes

  • (A)The pre-trip, every trip — safety is how the truck leaves the yard.
  • (B)Hours run legal, always — no schedule is worth a shortcut.
  • (C)A human answers — 24/7 dispatch, straight numbers, no runaround.
  • (D)The honest count — we will always tell you exactly how big we are.

The principles that will guide us there

  • Integrity
  • Character
  • Safety
  • Service
  • Trust
